# AtmoSync Logistics Control Tower Dashboard

The AtmoSync dashboard provides real-time visibility into shipment health, spoilage risk, and operational recommendations.

## Key Dashboard Features

### KPI Monitoring
- Total Telemetry Records
- Safe Shipments
- Monitor Shipments
- At-Risk Shipments

### Risk Analytics
- Shipment risk distribution
- Spoilage risk analysis
- Temperature fluctuation monitoring

### Operational Insights
- Recommended actions:
  - Continue to destination
  - Inspect at nearest hub
  - Reroute to nearest market

The dashboard enables logistics teams to identify potential spoilage events and take proactive decisions.
